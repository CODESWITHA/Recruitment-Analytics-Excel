# Recruitment-Analytics-Excel
An interactive Excel recruitment analytics dashboard analysing 120 candidate records, hiring KPIs, application trends and recruitment performance using PivotTables, charts and slicers.

## Key Findings

### 1. Recruitment Pipeline and Hiring Performance

Out of the 120 applications analysed, 25 resulted in successful hires, representing an observed hiring rate of **20.83%**.

However, 78 applications (65%) remain in progress. This indicates that the current hiring rate does not represent the final recruitment outcome, as a substantial proportion of candidates have yet to reach a final decision of Hired.

Recommendation:Continue monitoring outstanding applications and regularly update recruitment KPIs to provide a more accurate picture of overall hiring performance.

### 2. LinkedIn Demonstrates the Strongest Recruitment Performance

LinkedIn generated the highest number of applications (58), accounting for **48.3% of all applications**. It also produced 19 of the 25 recorded hires, representing **76% of successful hires**.

LinkedIn's observed hiring rate was **32.76%**, compared with 21.43% for referrals and 10.53% for Bayt.com.

These findings suggest that LinkedIn is currently the strongest performing recruitment source in terms of both application volume and recorded hiring outcomes.

Recommendation: LinkedIn appears to be the most successful recruitment source so far, so it may be worth focusing more recruitment efforts on this platform. However, we should continue monitoring the other sources to see how many applicants go on to be hired.

### 3. Consistent Application Volumes Between March and June

Application volumes remained relatively consistent between March and June, ranging from 20 to 21 applications per month. May recorded the highest monthly volume, with **21 applications**.

Together, these four months accounted for 81 applications, representing **67.5% of the dataset**.

Although July recorded only 3 applications, the dataset ends on 4 July 2026. Therefore, July represents an incomplete reporting period and cannot be directly compared with the preceding months.

Recommendation: Use monthly application trends to support recruitment workload planning. Additional historical data would be required to determine whether the observed pattern reflects a recurring seasonal trend.
